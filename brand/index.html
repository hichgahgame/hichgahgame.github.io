Brand

One look, from the website to every game

Everything here comes from one file, brand/tokens.json. The website reads it as CSS and every game reads it as C#, so a star, a button or the logo looks the same wherever you meet it.

Logo

The circle of time, opened by a single moment

The ring is the clock, left open. The dot is the Now, stepping out of it. Use the full lockup when there is room, and the mark on its own for icons, splash screens and small spaces.

  • Leave clear space around the logo at least the size of the dot's ring gap.
  • Keep the mark at 16px or larger, and the lockup at 96px wide or larger.
  • Don't recolour, stretch, rotate or add effects. On busy art, use the white lockup or the app icon.

Colour

Vivid, warm and never harsh

Each hue has four shades: base for fills, deep for edges and text on light, soft for light panels and night for accents on dark. Every text pairing passes WCAG AA, checked each time the tokens are built.

In Unity

The same tokens, as C#

Run brand/sync-unity.sh from this repo to copy Assets/Hichgah/Brand/ (the HichgahBrand.cs class and the logo PNGs) into every game. Change colours in tokens.json, run brand/build.py, then sync again.

using Hichgah.Brand;

starImage.color   = HichgahColors.Game.Star;          // sun
button.color      = HichgahColors.Game.PrimaryButton;  // violet
buttonEdge.color  = HichgahColors.Violet.Deep;
panel.color       = HichgahColors.Pink.Soft;
splash.colorGradient = HichgahGradients.Now;            // violet → pink → tangerine

yield return Fade(panel, HichgahMotion.Calm);          // 0.6 s; Fast (0.15 s) only for taps
